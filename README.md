# Start-4-All
Statistical analysis code and plans for the performance evlauation of the Start 4 All programme.

## Directory StatisticalAnalysisPlan
Contains the final SAP version together with JAGS script at the time of the SAP compilation.

## Directory Results
Contains the up-to-date results / complete study report inclusive of full code (in the quarto script) and JAGS files as used for the actual analysis. (Minor) deviations from the SAP are highlighted in the report.
